# Таблицы отображения id (WoG/H3 ↔ Olden Era)

Плагин читает `*.json` из `BepInEx/config/WoG/id-maps/` (туда эту папку копирует `tools/deploy/deploy.ps1`). Файлы
содержат только id и номера — без данных игры, — поэтому коммитятся; генерируемые пересобираются из `Core.zip`
пользователя после обновления игры. Строка с `engine: null` не отображена: команды ERM с таким id сообщают
*unsupported*, ничего не подменяется.

* `creature.json` — двусторонняя, `{"wog": номер существа H3/WoG, "engine": sid юнита Olden Era | null, …}`; генерируется
  `WoG.ErmTool idmap-creatures <Core.zip> <creature.json>` (`tools/WoG.ErmTool/CreatureMap.cs`):
  * город H3 → фракция Olden Era по теме: Замок → human (Храм), Оплот → nature (Роща), Некрополис → undead,
    Темница → dungeon, Инферно → demon (Рой), Сопряжение → unfrozen (Раскол); у Башни, Цитадели и Крепости фракции в
    Olden Era нет, они не отображены;
  * уровень H3 L: базовое существо → базовый юнит фракции уровня L, улучшение → его юнит `_upg`;
  * нейтралы с тем же существом: полурослик, крестьянин, сказочный дракон;
  * каждый юнит Olden Era без номера H3 (`_upg_alt`, нейтралы Olden Era) получает номер от 1000; выданные ранее номера
    сохраняются.
* `resource.json` — двусторонняя: дерево 0, ртуть 1, руда 2, сера 3 (в Olden Era нет), кристаллы 4, самоцветы 5,
  золото 6.
* `skill.json` — двусторонняя, составлена вручную: вторичный навык H3 (Format SS) → sid навыка героя Olden Era, по
  эффекту (Логистика → `skill_logistic`, Удача → `skill_luck`, Некромантия → `skill_faction_undead`, Имущество →
  `skill_economy`, Обучаемость → `skill_enlightenment`, Нападение → `skill_assault`, Доспехи → `skill_protection`, …;
  14 из 28). Навыки H3 без аналога (`"engine": null`: Поиск пути, Стрельба, Навигация, Мудрость, Мистицизм, Орлиный
  глаз, четыре школы магии, Грамотность, Артиллерия, Интеллект, Первая помощь) читаются как не изученные; навыкам только
  Olden Era выданы номера от 1000, скриптам они не показываются.
* `spell.json` — двусторонняя, составлена вручную (`"engine"` сверены с `DB/magics`): заклинание H3 0..69 → sid
  заклинания Olden Era, по эффекту (Волшебная стрела → `bonus_magic_pure_bolt`, Благословение → `day_2_magic_sharp_edge`
  «больше урона обычной атакой», Замедление → `night_2_magic_web` «меньше скорости», Слепота → `night_8_magic_sleep`,
  Полёт → `neutral_magic_shadow_form`, …; 37 из 70). Заклинания без аналога (корабли, школы стихий и защиты от них,
  мораль и удача, призыв элементалей, …) читаются как неизвестные. Герой-специалист знает заклинание в варианте
  `_special` — это тот же номер. Заклинаниям только Olden Era выданы номера от 1000.

При загрузке сохранения таблицы из этих файлов заменяют копии, сохранённые в его состоянии WoG (файлы могут быть новее
сохранения); номера, выданные во время игры (номера героев), берутся из сохранения.
* `object.json` — односторонняя, `{"engine": sid объекта, "tag", "type", "subtype", "h3", "note"}`: объект карты Olden
  Era → тип/подтип объекта H3 (Format OB ERM); один тип H3 могут представлять несколько объектов Olden Era, при
  размещении типа H3 берётся его первый sid. Генерируется `WoG.ErmTool idmap-objects <Core.zip> <object.json>
  [artifact.json]` (`tools/WoG.ErmTool/ObjectMap.cs`) из `DB/map/objects`:
  * аналог выбирается по тому, что объект делает (`DB/objects_logic`), а не по названию: рудники по `resName`,
    мельница (ресурсы раз в неделю) → Ветряная мельница 112, сторожевая башня (открывает туман) → Обсерватория 58,
    колодец маны → Магический колодец 49, рынок → Торговая площадь 99, кузница (продаёт предметы) → Чёрный рынок 7,
    святилище жертвоприношения → Алтарь жертвоприношения 2, склеп героя → Склеп 84, конюшни → Конюшни 94, …;
  * `custom_X` (варианты генератора с другими наградами) отображается как `X`;
  * города по фракции, как существа (тип 98, Format T), жилища `barracks_<фракция>_<уровень>` → жилище города того же
    уровня (тип 17, Format CG), порталы `portal_N…` → двусторонний монолит N−1 (тип 45), артефакты → тип 5 (подтип из
    `artifact.json`, когда он есть, иначе −1);
  * любой другой интерактивный объект Olden Era получает тип от 1000 (по порядку sid, сохраняется между запусками);
    декорации (окружение, животные, эффекты, блоки) — не объекты ERM, в файл не входят.
  Отряды монстров (тип 54) и героев на карте (тип 34) в этом файле нет: адаптер добавляет их из состояния игры (отряд
  из нескольких типов юнитов считается по первому юниту, через `creature.json`).
