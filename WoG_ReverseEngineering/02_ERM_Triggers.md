## Правила порядка (из кода)

1. При посещении объекта движок генерирует по порядку: позиционный `OB x/y/l`, затем `OB тип/подтип`,
   затем `OB тип` (`ERM2Object`) — каждый пре-триггер до родного посещения, `$`-пост-триггеры после, в том же
   порядке.
2. `HM-1` выполняется до `HM#`; `HL-1` — до `HL#` (разные id событий, генерируются в этом порядке).
3. Начало боя: `BA0` (или `BA50` на ПК защитника в сети), затем `BA52`; затем `BF` при подготовке поля;
   затем `BR` с `v997=-1` (до тактики), `BR` с `v997=0`, далее на каждое действие `BG0`/`BG1`, на каждый
   раунд `BR`. Конец: `BA1`/`BA51`, затем `BA53`.
4. В пределах одного id события — все секции в порядке загрузки (§6 `01_ERM_Language.md`).
5. `FU:E` завершает секцию; следующая секция того же события всё равно выполняется.
